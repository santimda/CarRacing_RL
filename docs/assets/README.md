# Curated Assets

This directory contains lightweight, portfolio-ready plots and GIFs. Keep
model ZIPs, replay buffers, TensorBoard event files, and raw training outputs
under the ignored `outputs/` directory. GitHub renders the GIFs as animations.

Suggested assets:

- `ppo-training-metrics.png` and `drq-sac-training-metrics.png`, using four
  selected diagnostic panels each;
- `ppo-demo.gif` and `drq-sac-demo.gif`, both evaluated on demo seed `48`.
